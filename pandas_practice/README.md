# pandas practice

Dataframe drills: the reshaping, grouping, joining and window operations that come up in
take-homes and in live SQL-to-pandas translation questions.

Same rules as the rest of the repo. Each drill is one file holding a small fixed input frame, a
`_brute` version written with plain loops or `itertuples`, the idiomatic vectorised version, and a
test asserting the two agree — including on the cases that catch people out: empty frames, all-NaN
groups, duplicate index labels, and mixed dtypes.
